# ConnLog 少人数テストユーザー招待前 最終QA記録

確認日：2026年8月28日

対象環境：Production

対象コミット：`f0ddb83`

## 1. この文書の目的

この文書は、ConnLogへ少人数のテストユーザーを招待する前に、Production環境の主要機能と主要導線を最終確認し、その結果と公開可否の判断を記録するものである。

これまでに実施したコード監査、RLS・API確認、テストアカウントA・Bによるデータ分離確認、Claude Codeによる独立一次監査、Supabase・Vercel設定確認を置き換えるものではない。

今回は、これらの確認と修正を反映した最新版のProduction環境で、一般利用者が実際に操作する主要導線が正常に動作することを確認する。

## 2. 確認方針

最終QAは次の方針で行う。

- Production環境を対象とする
- 既存のテストアカウントA・Bを使用する
- メールアドレス、パスワード、APIキーなどの秘密情報は記録しない
- イベントの追加・更新・削除にはテストデータだけを使用する
- 他ユーザーのデータが表示・更新・削除されないことを確認する
- アカウント削除は、削除してよい専用アカウントがある場合だけ実施する
- QA中に不具合を発見した場合は、このブランチへ修正を混ぜず、別の修正ブランチとPRで対応する
- テストユーザーの実際の招待は、最終QAと公開可否判断が完了するまで行わない

## 3. 判定基準

次のいずれかが確認された場合は、テストユーザーの招待をいったん見送る。

- ログインや主要画面への移動ができない
- イベントの検索・保存・更新・削除が正常に動作しない
- 他ユーザーのデータを閲覧・更新・削除できる
- パスワード変更などの重要操作で本人確認が機能しない
- 利用を継続できない重大な画面崩れやエラーが発生する
- 秘密情報の露出や認証回避につながる問題が見つかる

表示上の軽微な違和感など、主要機能と安全性を損なわない問題は、内容と対応方針を記録したうえで公開可否を判断する。
