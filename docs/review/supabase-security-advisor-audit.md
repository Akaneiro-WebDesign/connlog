# ConnLog Supabase Security Advisor 監査メモ

最終確認日：2026年7月30日

## 目的

Supabase Security Advisorの警告を確認し、MVP公開前に重大な未解決事項が残っていないかを記録する。

あわせて、Postgres更新後も認証・データ操作・アカウント間のデータ分離が正常に機能することを確認する。

## 実施内容

以下の警告対応・確認を実施した。

- DB関数の `Function Search Path Mutable` 関連を修正
- 未使用の `insert_user_tag` 関数を削除
- `handle_new_user` 関数の直接実行権限を制限
- 未使用の `pgjwt` 拡張を削除
- Postgres更新前にDBのデータ・構造をバックアップ
- Postgresを `15.8.1.094` から `17.6.1.147` へ更新
- 更新後にSecurity Advisorを再確認
- 招待テストアカウントを使って主要導線を確認

## Security Advisor最終確認結果

2026年7月30日にSupabase Security Advisorを再確認した結果。

- Errors：0件
- Warnings：1件
- Info：0件

### 残存Warning

- `Leaked Password Protection Disabled`

これは、漏えい済みパスワードの利用を検知・拒否する保護機能が無効であることを示す設定上のWarningである。

漏えい済みパスワード保護はSupabaseのPro Plan以上で利用できる機能であり、現在利用しているFree Planでは有効化できない。

認証回避、データ漏えい、DB関数、RLSなどの実装上の問題が検出されたものではないため、既知のプラン制約として許容する。

将来Pro Planへ移行した場合は、有効化を検討する。

## Postgres更新後の主要導線確認

Postgres `17.6.1.147`への更新後、招待テストアカウントを使用して以下を確認した。

### 認証・招待

- Supabase Dashboardの `Send invitation` から招待メールを送信できる
- 招待メールを受信できる
- 招待リンクから初回パスワードを設定できる
- 設定したメールアドレスとパスワードで再ログインできる
- `Authentication → Users` に招待ユーザーが登録される

### イベント・データ操作

- イベントIDまたはURLでイベントを検索できる
- イベントを登録できる
- 登録したイベントがイベント履歴に表示される
- タグとメモを追加・保存できる
- ダッシュボードとスキル分析に登録内容が反映される
- 登録イベントを編集できる
- 登録イベントを削除できる

### データ分離・アカウント削除

- 招待テストアカウントから既存の開発アカウントのデータが表示されない
- 主要導線上でアカウント間のデータ分離が機能している
- テストアカウントを削除できる
- アカウント削除後にログイン画面へ遷移する
- `Authentication → Users` から削除したユーザーが消える

## 確認中に見つかった改善候補

アカウント削除後、完了メッセージが表示されず、そのままログイン画面へ遷移する。

削除処理自体は正常に完了しており、セキュリティ上の問題ではない。ただし、利用者には削除が成功したか分かりにくいため、以下をUX改善候補として別途対応する。

- ログイン画面に「アカウントを削除しました」などの完了メッセージを表示する

この改善候補は、Supabase監査完了やMVP開始を妨げるブロッカーとはしない。

## 最終判断

DB関数、関数実行権限、未使用拡張、Postgres更新に関するSecurity Advisorの警告は解消済みであることを確認した。

Postgres更新後も、認証、イベント操作、データ表示、アカウント間のデータ分離、アカウント削除の主要導線が正常に動作した。

残存する `Leaked Password Protection Disabled` はFree Planの制約として記録し、現時点ではMVP開始や外部コードレビュー依頼のブロッカーとはしない。

以上により、Supabase Security Advisorに関するMVP公開前の自己監査を完了とする。

なお、本記録の対象は、Supabase Security Advisorの確認と主要導線の手動テストであり、アプリケーション全体を対象とした網羅的なセキュリティ診断ではない。
