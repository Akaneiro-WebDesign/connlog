# ConnLog 少人数テストユーザー招待・フィードバック運用手順

最終更新：2026年9月6日

## 1. 目的

この文書は、ConnLogへ少人数のテストユーザーを招待する際の手順、案内内容、フィードバックの受け付け方を整理するものである。

初回は1〜3名を目安に招待し、利用状況と対応余力を確認しながら段階的に人数を増やす。

## 2. 招待前の確認

招待を送る前に、次の項目を確認する。

- Productionの最新デプロイが`Ready`になっている
- Supabase Authで一般登録と匿名ログインが無効になっている
- ConnLogの`/signup`が招待制案内を表示している
- 招待対象者のメールアドレスに誤りがない
- 不具合報告を受け取る連絡手段を対象者と共有している
- 一度に招待する人数が、個別に対応できる範囲に収まっている

## 3. 招待手順

1. Supabase Dashboardの対象プロジェクトを開く
2. `Authentication`から`Users`を開く
3. `Send invitation`を選択する
4. 招待対象者のメールアドレスを確認して入力する
5. 招待メールを送信する
6. 対象者へ、招待リンクを1時間以内に開くよう案内する
7. 対象者が招待リンクから初回パスワードを設定できることを確認する
8. 対象者がConnLogへログインできることを確認する

メールアドレス、パスワード、招待トークンなどの秘密情報は、この文書やGitHubへ記録しない。

## 4. テストユーザーへの案内文

以下を基本形とし、相手や連絡手段に合わせて調整する。

> 個人開発中のWebアプリ「ConnLog」のテスト利用にご協力いただきありがとうございます。
>
> ConnLogは、connpassのイベントを保存し、タグやメモを付けて学習履歴を振り返るアプリです。
>
> Supabaseから招待メールが届きましたら、メール内のリンクを1時間以内に開き、初回パスワードを設定してください。
>
> 利用中に分かりにくい点、不具合、表示崩れ、使いにくい点などがありましたら、招待をご案内した連絡手段からお知らせください。
>
> 不具合をご連絡いただく際は、パスワードや招待リンクなどの秘密情報を送らないようお願いいたします。

## 5. フィードバックで確認する内容

テストユーザーには、可能な範囲で次の情報を知らせてもらう。

- 操作していた画面
- 行った操作
- 期待していた結果
- 実際に起きた結果
- 発生した日時
- 使用した端末とブラウザ
- 再読み込み後も同じ問題が起きるか
- 秘密情報を含まないスクリーンショット

パスワード、招待リンク、認証トークン、メールアドレスなどの秘密情報は送らないよう案内する。

## 6. 問題発生時の対応

次の問題が確認された場合は、新しいユーザーの招待をいったん停止する。

- ログインや初回パスワード設定ができない
- 他のユーザーのイベント、タグ、メモが表示される
- 他のユーザーのデータを変更または削除できる
- 主要機能を継続して利用できない
- 秘密情報の露出や認証回避につながる可能性がある
- 同じ重大な問題が複数の利用者で発生する

重大ではない表示上の問題や改善要望は、内容を記録して優先順位を判断する。

## 7. 招待後の記録

個人情報や秘密情報を含めず、次の内容を記録する。

- 招待を実施した日
- 招待人数
- 初回パスワード設定とログインの成否
- 報告された問題の概要
- 招待を継続、拡大、停止する判断
