# ConnLog テストユーザー募集バナー制作方針

作成日：2026年9月12日

## 1. 目的

この文書は、ConnLogのテストユーザー募集時にXなどへ添付するバナーの内容と制作方針を整理するものである。

バナーでは、ConnLogが何をするWebアプリかを実際の画面と短い文言で伝え、開発中のテスト版を試してくれる人へ届きやすくする。

募集条件、応募から招待までの流れ、個人情報の取り扱いは、次の文書を参照する。

- [初回テストユーザー募集計画](./test-user-recruitment-plan.md)
- [初回テストユーザー募集文案](./test-user-recruitment-message.md)
- [少人数テストユーザー招待・フィードバック運用手順](./test-user-invitation-guide.md)

## 2. バナーで伝える内容

バナーでは、次の内容を優先して伝える。

- ConnLogのテスターを募集していること
- connpassイベントを記録し、学習履歴を振り返るWebアプリであること
- タグ、メモ、グラフを使えること
- 招待制のテスト版であること

募集人数、テスト期間、応募方法、注意事項などの詳細は、本文または応募後の個別案内で伝える。バナーへ情報を詰め込みすぎない。

## 3. 掲載文言

バナーには、次の文言を基本として使用する。

- 見出し：`ConnLog テスター募集`
- 主な説明：`connpassイベントを、学びの記録に。`
- 補足：`タグ・メモ・グラフで振り返るWebアプリ`
- 小さな補足：`招待制テスト版`

「初期ユーザー」「正式公開中」「継続利用」など、テスト版の位置付けと異なる印象を与える表現は使用しない。

## 4. 画面の選び方

バナーの中心には、実際のConnLogの画面を使用する。

主な候補は次のとおりとする。

- メイン画面：`/dashboard`
  - タグ別の傾向や週ごとの参加数が分かり、ConnLogで振り返りができることを伝えやすい
- 補助画面：`/events`
  - 保存したイベント、タグ、メモを扱えることを補足できる
- 必要に応じて：`/skills`
  - タグをもとにした学習傾向を確認できることを補足できる

ログイン、初回パスワード設定、プロフィールの画面は、募集バナーの中心には使用しない。

## 5. スクリーンショットの準備

スクリーンショットは、公開して問題のないテストデータを使って撮影する。

次の情報が写らないことを確認する。

- メールアドレス
- 表示名、自己紹介、ユーザーID
- 招待リンク、認証情報、ブラウザのアドレスバー
- 実在の応募者やテストユーザーに関する情報
- 秘密情報や非公開情報
- 失われると困る内容を含むメモ

ブラウザ全体ではなく、アプリ画面の必要な範囲だけを切り出す。撮影後は、投稿前に拡大して内容を再確認する。

## 6. レイアウトとデザイン

横長の16:9を基本とする。

- 左側に見出し、説明、テスト版であることを配置する
- 右側にConnLogの実画面を大きく配置する
- 文字は少なくし、画面が読み取れる大きさを確保する
- ConnLogの画面で使われている色を基調にし、白または明るい背景で読みやすくする
- 装飾的なイラストや人物素材より、実際の画面を優先する
- 文字は画像生成に任せず、Canva、Figma、画像編集ソフトなどで配置する

AI生成画像を使う場合も、実画面を置き換える目的では使用しない。背景の補助的な素材にとどめ、見出しや説明文は人が確認して配置する。

## 7. 制作の流れ

1. 公開用テストデータを表示した画面を用意する
2. `/dashboard`を中心に、必要に応じて`/events`または`/skills`を撮影する
3. 個人情報や秘密情報が写っていないことを確認する
4. 横長のレイアウトへ、見出しと実画面を配置する
5. スマートフォンで見ても見出しと画面の要点が読めるか確認する
6. PNG形式で書き出す
7. Xの募集文と合わせて確認し、公開前チェックを行う

## 8. 公開前チェック

- 実際のConnLog画面を使用している
- 見出しに「テスター募集」と書かれている
- テスト版であることが分かる
- 実装されていない機能を示していない
- 正式サービスの継続提供やデータの長期保存を保証する表現になっていない
- 募集人数やテスト期間を必ず載せる前提になっていない
- メールアドレス、ユーザーID、招待リンクなどが写っていない
- 小さな画面でも文字が読み取れる
- X向け募集文と内容が矛盾していない
