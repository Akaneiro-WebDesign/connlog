# ConnLog 運用文書

このディレクトリには、少人数のテストユーザーを募集・招待し、フィードバックを受け取るための運用文書を置く。

## 文書一覧

- [初回テストユーザー募集計画](./test-user-recruitment-plan.md)
  - 募集対象、募集場所、募集期間、テスト期間、応募から招待までの流れを定める
- [初回テストユーザー募集文案](./test-user-recruitment-message.md)
  - Xや個人開発コミュニティへ掲載する募集文と、応募者への個別案内文を定める
- [テストユーザー募集バナー制作方針](./test-user-recruitment-banner-brief.md)
  - 募集投稿に添付するバナーの文言、使用画面、スクリーンショット、デザインの方針を定める
- [少人数テストユーザー招待・フィードバック運用手順](./test-user-invitation-guide.md)
  - 参加者決定後の招待、初回設定の確認、フィードバックの受け付け方を定める

## 利用する順番

1. 募集を始める前に、募集計画と募集文案を確認する
2. 募集投稿へバナーを添付する場合は、バナー制作方針を確認する
3. 応募者へ個別案内を送り、参加意思を確認する
4. 参加者が決まったら、招待・フィードバック運用手順に従って招待する
5. テスト期間中は、受け取ったフィードバックを個人情報や秘密情報を含めない形で整理する

個人情報、メールアドレス、招待リンク、パスワード、認証トークンなどは、このディレクトリの文書やGitHub Issueへ記録しない。
