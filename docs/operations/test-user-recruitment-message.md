# ConnLog 初回テストユーザー募集文案

作成日：2026年9月9日

## 1. 目的

この文書は、ConnLogの初回テストユーザーを募集する際に使用する公開投稿と、応募者へ個別に案内する文章を整理するものである。

募集条件と運用方針は、[ConnLog 初回テストユーザー募集計画](./test-user-recruitment-plan.md)に基づく。

実際に募集する際は、掲載場所や募集状況に合わせて日付などを調整する。

## 2. 募集時の表現方針

## 2. 募集時の表現方針

募集時は、「テスター」と表現する。

公開投稿では、掲載先に応じて次の内容を簡潔に伝える。

- 開発中の招待制テスト版であること
- ConnLogでできること
- connpassを利用した経験がある人を対象とすること
- 毎日の利用や専門的な不具合調査は求めないこと
- 参加希望はリプライまたはDMで受け付けること

謝礼、データの取り扱い、招待方法などの詳細は、応募後、本人の参加意思と招待先メールアドレスを確認する前に個別に案内する。

## 4. 個人開発コミュニティ向け募集文案

> 【Webアプリ「ConnLog」テスター募集】
>
> 個人開発中のWebアプリ「ConnLog」を試していただける方を募集します。
>
> ConnLogは、connpassの参加イベントを保存し、タグやメモを付けて学習履歴を振り返るアプリです。登録した内容をもとに、関心のある分野や参加傾向をグラフで確認できます。
>
> 対象となる方は、connpassを利用した経験があり、開発中の招待制テスト版であることをご理解いただける方です。
>
> テスト期間は、初回設定から14日間程度を予定しています。毎日の利用や、専門的な知識を使った詳しい不具合調査は必要ありません。無理のない範囲でアプリを操作し、分かりにくかった点や気になった点を簡単に教えていただけると助かります。
>
> ご協力いただける方は、DMまたは個別メッセージでご連絡ください。招待に必要なメールアドレスは、参加内容をご確認いただいた後に個別に伺います。

## 5. 応募者への個別案内文

> ConnLogのテスト利用に関心を持っていただき、ありがとうございます。
>
> ConnLogは、connpassの参加イベントを保存し、タグやメモ、グラフで学習履歴を振り返る、個人開発中のWebアプリです。
>
> 今回のテスト期間は、初回パスワード設定の完了から14日間程度を予定しています。毎日の利用や、すべての機能の確認、専門的な不具合調査は必要ありません。
>
> 今回は謝礼のご用意はありませんが、無理のない範囲でご協力いただけるとうれしいです。
>
> ConnLogは開発中のテスト版であり、サービスの継続的な提供や登録データの長期保存は保証していません。重要な情報、機密性のある内容、失われると困る内容は登録しないようお願いいたします。
>
> 利用中に分かりにくかった点、不具合、表示上の問題、使いにくかった点などがありましたら、可能な範囲でお知らせください。
>
> 参加を希望される場合は、この内容をご確認のうえ、その旨をご返信ください。参加意思を確認した後、招待先として使用するメールアドレスを個別に伺います。
>
> パスワードや、受信した招待メールのリンクは、開発者を含む他人へ送らないようお願いいたします。

## 6. 応募受付後の確認事項

応募者から連絡を受けた後は、次の事項を確認する。

- 応募者が個別案内の内容を確認している
- 本人がテストへの参加を希望している
- 謝礼を設けていないことについて認識が一致している
- テスト期間の目安を理解している
- 継続提供とデータの長期保存を保証しないことを理解している
- 重要な情報や機密性のある内容を登録しないことを理解している
- 本人が招待先として指定したメールアドレスを個別に確認している
- パスワードや招待リンクを共有しないよう案内している

確認後は、[ConnLog 少人数テストユーザー招待・フィードバック運用手順](./test-user-invitation-guide.md)に従って招待する。

## 7. バナーへ掲載する文言

募集時に使用するバナーは、実際のConnLogの画面を中心に構成する。

掲載する文言の候補は次のとおりとする。

- `ConnLog テスター募集`
- `connpassイベントを、学びの記録に`
- `タグ・メモ・グラフで振り返る`
- `招待制テスト版`

画像の作成とデザインの確定は、募集文の確定後に別の作業として行う。

## 8. 投稿前の確認

募集文を投稿する前に、次の項目を確認する。

- 募集人数と募集期間が現在の計画と一致している
- 応募方法が明確になっている
- 公開投稿に個人情報や秘密情報が含まれていない
- 正式サービスや継続提供を保証する表現になっていない
- 相互テストを条件とする表現が含まれていない
- 添付画像にメールアドレス、ユーザーIDなどが写っていない
- 応募者へ個別案内を送ってから招待先メールアドレスを確認する流れになっている
